# 🛒 SmartRetail (SmartReatile): AI-Powered Campus Marketplace

> **Buy. Sell. Save. Inside Your Campus.**

SmartRetail (SmartReatile) is a localized e-commerce platform and price recommendation system designed exclusively for verified college students.

Developed for **VIT Bhopal University — Group 177, Project Exhibition-I**, the platform aims to reduce online scams and unfair pricing by creating a **hyper-local, secure, and student-focused trading environment** for temporary necessities such as books, lab equipment, cycles, electronics, and hostel essentials.

---

## 📸 Platform Interface & Features

### 📊 Dashboard & Metrics

A modern, dark-themed and responsive user interface built using **HTML5, CSS3, and JavaScript**.

The dashboard provides important marketplace information and statistics such as:

- Active students
- Items listed
- Items sold
- Marketplace activity
- User-friendly navigation

### 🔐 Secure Campus Login

SmartRetail uses campus-based verification to create a trusted student marketplace.

Access is restricted to verified **college/campus email holders**, helping reduce unauthorized access and improving trust between buyers and sellers.
